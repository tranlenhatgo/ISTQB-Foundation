## Research summary

- The certification is named **CTFL v4.0**, while the current English syllabus is **v4.0.1**. Version 4.0.1 is the 2024 errata release and should be used instead of the original v4.0 syllabus.
- The exam has 40 multiple-choice questions worth 40 points. The pass mark is 26 points, the standard duration is 60 minutes, and eligible non-native-language candidates may apply for 25% additional time.
- CTFL tests learning objectives at K1, K2, and K3. The examinable areas are fundamentals, testing throughout the lifecycle, static testing, test analysis and design, managing test activities, and test tools.
- ISTQB's minimum self-study materials are the current syllabus and official glossary. The official sample exams should also be used for timed practice.

## How to use this collection

1. Treat the [v4.0.1 syllabus](official/ISTQB-CTFL-Syllabus-v4.0.1.pdf) as the authority for concepts and official wording.
2. Use the [live ISTQB Glossary](https://glossary.istqb.org/en_US/search) for current definitions. ISTQB maintains the glossary as a web application rather than a fixed CTFL PDF.
3. Take each sample question paper closed-book in 60 minutes. Do not open its answer file until the attempt is complete.
4. Use the answer file to classify every wrong or guessed answer by syllabus chapter and learning objective.
5. Keep at least one sample set unused until the final readiness check.
